# 转角的罗森 · LAWSON MINI WORLD

一个可交互的 Three.js 微缩街景：蓝白招牌的罗森便利店立在街角，室内亮着暖光，货架、收银台、吧台一应俱全；门外樱花树、售货机、扭蛋机、长椅和小猫各自安静待着。你可以转动视角、切换昼夜与晴雨雪，点击门、售货机和扭蛋机，看这个小小的世界做出回应。

仓库：<https://github.com/atrestandbed-bot/luosen>

> **声明**：本项目为非官方粉丝作品，仅用于学习与技术交流，与罗森（LAWSON）公司无任何关联或合作；"LAWSON / 罗森"及相关商标的权利归其权利人所有。请勿将本项目用于商业用途。

## 功能特性

### 场景与建筑

- 罗森便利店微缩建筑：平屋顶、屋顶空调、蓝白招牌、玻璃店面与自动门
- 完整室内陈列：收银台、商品货架、冷藏柜、窗边吧台、店员与顾客
- 室外街景：樱花树、招牌立柱、盆栽、长椅、小猫、立牌、扭蛋机、自动售货机、垃圾桶、自行车
- 道路细节：人行道、盲道、斑马线、护栏、排水口与连续白边线

### 氛围与控制

- 昼夜切换：白天 / 黄昏 / 夜晚，背景、环境光与建筑照明同步平滑过渡
- 天气切换：晴 / 雨 / 雪；雨天有雨滴、积水与湿润路面，雪天屋顶、人行道、马路分层积雪
- 一键雨夜：直达氛围感最强的组合
- 正交（默认）/ 透视镜头一键切换
- 展开屋顶：屋顶设备同步抬升，露出室内陈列
- 环境声、隐藏 UI、保存 PNG 截图

### 点击交互

| 目标 | 反馈 |
|------|------|
| 入口自动门 | 门扇滑动开合 |
| 自动售货机 | 随机一瓶饮料掉落 → 出货口开门 → 停留 5 秒 → 关门复原 |
| 扭蛋机（两台） | 仅对应机器内的球弹跳滚动后停下 |
| 垃圾桶（三个） | 仅对应桶盖朝玻璃墙方向打开，停 2 秒后关闭 |
| 街角小猫 | 被叫醒，抬头看你 |

## 技术栈

- [Three.js](https://threejs.org/) ^0.186 — 3D 场景、光照与阴影
- [Vite](https://vite.dev/) ^8 — 开发与构建
- 原生 JavaScript / CSS，无框架依赖

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 生产构建（输出到 dist/）
npm run build

# 本地预览构建产物
npm run preview
```

## 操作说明

**桌面端**

- 拖动旋转 / 滚轮缩放 / Shift＋左键平移
- 点击自动门、售货机、扭蛋机、垃圾桶、小猫触发交互
- 右上角工具条：环境声、截图、镜头切换、隐藏界面
- 底部控制栏：昼夜、天气、展开屋顶、玻璃门开关、一键雨夜

**手机端**

- 单指旋转 / 双指缩放平移
- 按钮集中到底部并缩小，“展开屋顶”竖排在“一键雨夜”左侧
- 兼容安全区域，隐藏桌面操作说明

## 部署

纯静态站点，构建后把 `dist/` 部署到任意静态托管即可：

- **GitHub Pages**：`npm run build` 后发布 `dist/`。若部署到项目子路径（`https://用户名.github.io/luosen/`），需在 `vite.config` 中设置 `base: '/luosen/'` 后重新构建
- **Vercel / Netlify / Cloudflare Pages**：构建命令 `npm run build`，输出目录 `dist`

## 已知限制与未完成部分

- 环境声目前是合成音（174Hz 正弦低鸣），并非真实录制的街景环境音
- 商品、人物等使用轻量几何体表现，非真实贴图模型
- 手机端布局经过浏览器模拟验证，未在真机全型号测试；极端窄屏（<360px）下按钮文字可能偏挤
- 阴影在低性能设备（`hardwareConcurrency < 5`）会自动降低分辨率，画质略有差异
- 积雪、积水等粒子效果在大屏高帧率下与低性能设备的表现细节不完全一致

请直接制作一个完整、可运行的可交互3D便利店网页，主题为“转角的罗森 · LAWSON MINI WORLD”。使用Three.js，桌面端以横屏展示为主，同时适配手机。请完成实际网页并提供可打开体验的链接。

1. 整体风格与建筑
先查找网上罗森便利店的实景图片，参考其蓝白招牌、玻璃店面、室内陈列和街边设施，制作精细、可爱的微缩街景。默认使用正交轴测视角，完整展示建筑和基座，保留适当留白。色彩清晰、有层次，采用柔和光照、自然阴影和冷暖对比。
建筑包含白色平屋顶、两台屋顶空调、蓝白色LAWSON招牌、玻璃墙、自动门和完整室内。室内布置收银台、商品货架、窗边吧台、店员与顾客；商品使用轻量几何表现，种类丰富、排列整齐。玻璃保持适度透明，让室内可见，同时保留反射和边框质感。
墙体、门窗、屋顶与地面位置对应。玻璃转角采用连续、圆滑的衔接，转角方杆与其他玻璃边框保持一致，避免重复立杆。自动门底部贴合入口地面，不能插入基座。

2. 室外街景与道路
室外布置樱花树、罗森招牌立柱、盆栽、长椅、小猫、白色罗森立牌、两台扭蛋机、一台自动售货机、三个垃圾桶和两辆不同颜色的自行车。
门前设施靠近玻璃墙，但留出合理间距和入口通道。物体落地、比例协调，避免悬空和穿插。室内外人物使用统一造型，衣服颜色可以不同；两名室外人物自然行走，步频与移动速度匹配，转身平滑。小猫需表现耳朵、眼睛、鼻子、爪子和尾巴，造型精细可爱。
道路、人行道和底座形成边缘圆滑的整体，各层外轮廓准确对齐。加入盲道、斑马线、低矮银色护栏、路边细排水口和连续白色边线。白线沿转角连续延伸，斑马线位置与其协调；不添加道路中心白线。检查路面高差、设施底部及基座接缝，避免穿模。

3. 视角与场景控制
支持鼠标拖动旋转、滚轮缩放、Shift＋拖动平移；手机支持单指旋转、双指缩放和平移。限制合理的缩放与俯仰范围，避免镜头进入地下。区分点击与拖动，旋转场景时不要误触设施。
提供白天、黄昏、夜晚，以及晴、雨、雪切换。切换过程平滑，背景、环境光和建筑照明同步变化。夜晚店内呈现温暖灯光，招牌与售货机适度发光。
雨天加入雨滴、局部积水和湿润路面效果。雪天屋顶、人行道和马路都要有积雪：雪堆大小、轮廓、朝向和疏密不同，有局部聚集，也有明显空白，避免沿路边均匀排列。积雪分别贴合屋顶、人行道和马路的高度，避开空调、建筑、室外设施及人物行走路线，不跨越路缘造成悬空或穿模。

4. 点击交互
入口自动门支持点击开合，门扇沿正确方向滑动，不能穿过边框。
点击自动售货机时，随机选择机内一瓶饮料，让它先掉落，再打开下方出货口的门。饮料到达出货口后停留5秒，随后消失，门关闭，原位置的饮料渐显恢复。正常状态下出货门关闭，动画进行时避免重复触发。
点击某台扭蛋机时，只让对应机器内的球弹跳、滚动，再逐渐停下；球不能穿过机器外壳。
三个垃圾桶分别可点击。点击某个垃圾桶时，仅对应桶盖朝玻璃墙方向打开，桶盖始终可见，完全打开后停留2秒，再平滑关闭。

5. 网页界面与手机适配
采用简洁非衬线字体、圆角按钮和统一背景色。提供展开屋顶、一键雨夜、切换镜头、环境声、隐藏UI和保存截图。屋顶展开时，屋顶设备同步移动，露出室内；隐藏UI后保留恢复入口。
手机端按钮适当缩小并集中放在底部，“展开屋顶”竖排放在“一键雨夜”左侧，隐藏电脑操作说明。兼容手机安全区域，避免按钮被遮挡或横向溢出。切换天气时，整个屏幕背景同步变化，包括画布外区域。
