# Design System

## Visual direction

A tiny Lawson corner shop at blue hour: cool street light, warm interior glow, and toy-like geometry with precise edges.

## Colors

- `--ink`: oklch(0.22 0.03 220)
- `--bg`: oklch(0.98 0 0)
- `--surface`: oklch(0.96 0.015 215)
- `--primary`: oklch(0.45 0.13 198)
- `--primary-light`: oklch(0.82 0.08 198)
- `--accent`: oklch(0.72 0.16 64)
- `--muted`: oklch(0.49 0.03 220)

## Typography

System sans stack; compact labels and balanced short headings.

## Components

Rounded control pills, compact status panel, single canvas scene, bottom action rail on small screens.

## Motion

State changes use 180–700ms eased transitions. Respect `prefers-reduced-motion`.
